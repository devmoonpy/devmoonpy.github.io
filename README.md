# mazino

A minimal, English-language personal website.

Live: https://devmoonpy.github.io/

## Local checks

Requires Node.js 22 or newer. No dependencies to install.

- `npm test` checks content, assets, and the static site structure
- `npm run build` copies the site into `dist/`
- Serve `dist/` with a local static web server to preview

GitHub Pages builds and deploys `main`. Previous site content remains recoverable in Git history.
